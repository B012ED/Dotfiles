1. Install nm-applet: sudo pacman -S networkmanager network-manager-applet gnome-keyring 

2. Enable the service to run automatically at boot
sudo systemctl enable NetworkManager.service

3. Start the service now
sudo systemctl start NetworkManager.service

4. Run nm-applet and grant permission if you created the nm-applet.sh file
